## Journal Club

논문은 PDF를 올리거나 직접 입력해 등록할 수 있습니다. PDF에서 제목·저자·DOI 링크를 찾아 기본 정보 입력을 돕고, 추출한 내용은 확인하고 수정할 수 있습니다.

연구 질문과 방법, 핵심 결과와 한계점을 정리해 논문의 내용을 돌아봅니다. 발표일과 발표자를 기록하고, 랩미팅에서 나온 질문과 의견을 논문별 토론으로 남길 수 있습니다.

제목·저자·발표자로 논문을 찾고 발표 상태를 살펴보며, 이전에 나눈 논의를 다음 연구를 위한 참고 자료로 이어갑니다.

로그인 없이 누구나 논문을 등록·열람·수정·삭제하고 토론에 참여할 수 있는 열린 연구 기록 공간입니다.
