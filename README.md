# 우리 연구실 홈페이지

Next.js 15 App Router, TypeScript strict, Tailwind CSS v4, Zustand로 만든 연구실 홈페이지입니다. 로그인 없이 누구나 논문을 등록·열람·수정·삭제하고 토론을 남길 수 있습니다.

## 실행

Node.js 24.13 이상을 사용합니다.

```powershell
cd "C:\AI\project\Lab HomePage"
npm install
npm run setup
npm run dev -- --hostname 127.0.0.1
```

브라우저에서 http://127.0.0.1:3000 을 엽니다. 포트나 접속 주소를 바꾸면 `.env.local`의 `APP_URL`도 함께 바꿉니다. 변경 요청은 이 주소와 일치하는 출처에서만 허용합니다. 이전 설정의 `BETTER_AUTH_URL`도 `APP_URL`이 없을 때 사용할 수 있습니다.

`setup`은 환경 설정이 없을 때 `.env.local`을 생성하고 `DATABASE_PATH` 경로의 SQLite 데이터베이스를 준비합니다. 기존 회원제 데이터베이스는 백업을 만든 뒤 공개 이용 구조로 이전합니다. 논문·토론·PDF 원본과 기존 작성자 기록은 유지하며 반복 실행할 수 있습니다. 기존 계정 데이터는 삭제하지 않지만 홈페이지나 API에서 조회하거나 사용하지 않습니다. 로그인, 가입, 멤버 승인, 이메일 인증 설정은 필요하지 않습니다.

## 구성

- 첫 화면: 노명균 교수님, Amin 박사과정, 이해찬 석사과정 소개
- 논문 공간: 제목·저자·원문 링크, 연구 질문·방법·핵심 내용·한계점, 발표일·발표자·발표 상태
- 토론: 논문별 질문과 의견 기록
- 공개 이용: 모든 방문자가 논문과 PDF를 등록·수정·삭제·다운로드할 수 있으며 논문 목록과 상세 화면에는 발표자만 표시

동시에 같은 논문을 수정하면 먼저 저장한 요청만 반영하고 나머지 요청에는 새로고침을 안내합니다. 삭제 전에는 확인 창이 표시됩니다.

PDF는 최대 50MB, 60쪽이며 추출 본문은 20만 자까지 처리합니다. 원본과 페이지별 추출문은 같은 데이터베이스에 저장합니다. 스캔 PDF처럼 본문을 읽을 수 없는 파일도 첨부와 직접 정리는 가능합니다.

**PDF로 시작하기**로 등록하면 PDF의 기본 정보와 첫 페이지에서 제목·저자·DOI 링크를 찾아 자동 입력합니다. API 키나 외부 서비스 호출 없이 처리하며, 추출한 값은 수정 화면에서 확인할 수 있습니다. 제목을 찾지 못하면 파일명을 사용하고 저자·링크는 빈칸으로 남깁니다. 기존 논문에 PDF를 첨부하거나 교체할 때는 빈 입력란만 채우며, **수정 내용 저장**을 눌러 반영합니다. PDF 형식과 메타데이터에 따라 결과가 달라질 수 있어 원문과 비교해야 합니다. 발표일·발표자와 요약 항목은 직접 입력합니다.

## AI 요약

실제 API 연결은 교수님 허락 전까지 보류합니다. 키가 없으면 PDF 기능과 직접 정리는 사용할 수 있고 AI 버튼은 연결 대기 상태로 표시됩니다.

연결이 허용되면 `.env.local`의 `OPENAI_API_KEY`와 `OPENAI_MODEL`을 설정하고 서버를 다시 실행합니다. 키는 브라우저나 코드에 입력하지 않습니다. API 사용 요금은 별도이며, 공개 사이트에서 누구나 호출할 수 있는 기능이므로 배포 전에 비용과 사용 한도를 정해야 합니다.

1. **새 논문 등록 → PDF로 시작하기**에서 파일을 등록합니다. 기존 논문은 수정 화면에서 PDF를 첨부합니다.
2. 연결된 경우 **AI 요약 초안 생성**으로 추출 본문을 OpenAI Responses API에 전송합니다.
3. 제목·저자, 연구 질문·방법·핵심 내용·한계점과 근거 페이지를 검토합니다.
4. **입력란에 적용**한 뒤 원문과 비교해 수정하고 **수정 내용 저장**으로 확정합니다. 생성만으로 기존 정리를 덮어쓰지 않습니다.

표·그림, 수치와 인용 근거는 직접 확인해야 합니다. PDF를 교체하거나 삭제해도 기존 정리 내용은 유지됩니다. 참고 서비스의 전체 기능과 동일하게 구현된 상태는 아닙니다.

공개 멤버 정보는 `lib/lab.ts`, 논문 정리 항목은 `lib/paper-sections.ts`에서 관리합니다. 사진은 제공되지 않아 이름을 바탕으로 한 표시를 사용합니다.

## 검증

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run test:http
```

테스트는 별도 임시 데이터베이스를 사용합니다. 공개 논문·토론 API, 입력과 출처 검증, 동시 수정, 기존 데이터 이전, 실제 PDF 추출과 파일 제한, 다운로드, 손상 파일 교체 시 데이터 보존을 확인합니다. AI 검증은 모의 응답만 사용하며 실제 API를 호출하지 않습니다.

`test:http`는 빌드 후 실행합니다. 임시 포트와 데이터베이스로 프로덕션 서버를 띄워 로그인 쿠키 없이 논문·PDF·토론 화면과 저장 동작을 확인하고 검증 데이터를 정리합니다.

개발 서버는 `.next-dev`, 배포용 빌드는 `.next`를 사용합니다. 빌드 후 `npm start -- --hostname 127.0.0.1`로 실행할 수 있으며, 같은 포트의 개발 서버는 먼저 종료해야 합니다.

## 남은 작업

랩미팅 일정 화면, 연구실 이름·사진·소개 확정, 허락 후 AI 연결, 외부 배포와 HTTPS·운영 백업이 남아 있습니다. 현재는 로컬에서 실행하며 외부에 배포하지 않았습니다. `.env*`, 데이터베이스와 설치 패키지는 Git에서 제외됩니다.
